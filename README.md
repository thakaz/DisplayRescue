# DisplayRescue

キーを押すだけで、画面構成(拡張・複製など)を元に戻せるWindows用のツールです。

画面が何も映っていなくても使えます。ログイン画面やロック画面でも効きます。

## こんなときに

「サブのモニタだけに映す」設定にしたまま、そのモニタの入力をゲーム機などに切り替えてしまうと、Windowsの画面がどこにも映らなくなります。こうなると設定アプリは操作できず、ログイン画面には構成を変える手段がそもそもありません。

DisplayRescueを入れておけば、キーを押すだけで見える状態に戻せます。

## 使えるキー

インストールした時点で、次のキーが使えます。

| キー | 画面構成 |
|---|---|
| `Ctrl` + `Alt` + `F8` | 拡張 |
| `Ctrl` + `Alt` + `F9` | 複製 |
| `Ctrl` + `Alt` + `F10` | メインのみ |
| `Ctrl` + `Alt` + `F11` | サブのみ |

- 普段のデスクトップ、ロック画面、再起動直後のログイン画面のどこでも効きます。
- 割り当ては変えられます(「[キーの割り当てを変える](#キーの割り当てを変える)」)。
- 切り替えの仕組みは`Win` + `P`と同じです。「メインのみ」「サブのみ」でどちらのモニタが残るかは、PCによって異なります。
- ネットワーク、ほかのアプリ、追加のランタイムは要りません。

## 動作環境

- Windows 10 / 11(64ビット)
- インストールと設定の変更には管理者権限が要ります

## インストール

1. [Releases](../../releases)から`DisplayRescue-<バージョン>-x64.zip`をダウンロードし、好きな場所に展開します。
2. 展開したフォルダの`DisplayRescue.exe`を開きます(管理者の確認が出ます)。
3. 「インストール」を押します。

これでキーが使えるようになります。PCを再起動しても自動で動きます。

> [!NOTE]
> exeにはまだコード署名をしていないため、SmartScreenの警告が出ることがあります。気になる場合は、ソースからビルドしてください(「[ソースからビルドする](#ソースからビルドする)」)。

### 新しい版に更新する

新しいzipを展開し、その中の`DisplayRescue.exe`を開いて「再インストール」を押します。キーの割り当てはそのまま引き継がれます。

### アンインストール

展開したフォルダの`DisplayRescue.exe`を開いて「アンインストール」を押します。

サービス、キーの設定、`C:\Program Files\DisplayRescue`が削除されます。次のものは残るので、不要なら手で消してください。

- 展開したフォルダ
- ログ(`C:\ProgramData\DisplayRescue`)

## キーの割り当てを変える

1. 展開したフォルダの`DisplayRescue.exe`を開きます(フォルダを消してしまった場合は、zipをもう一度ダウンロードして展開します)。
2. 変えたい操作の入力欄を選び、割り当てたいキーを押します。
3. 「OK」か「適用」を押します。変更はすぐに反映されます。

> [!WARNING]
> `Ctrl`も`Alt`も付けないキー(`A`だけ、`Shift` + `A`など)は、なるべく避けてください。割り当てたキーはWindows全体で横取りされるため、普段の入力に使えなくなります。ログイン画面でパスワードが打てなくなると、自力では戻せません。それでも割り当てる場合は、確認のためにもう一度保存を押します。

`F13`〜`F24`は普段の入力に使わないので、単体で割り当てても問題ありません。マクロキーや自作キーボードなど、キーボード側で`F13`〜`F24`を送るように設定できるなら、そのボタン1つで切り替えられます(ログイン画面でも効きます)。ただし、PowerToysなどのソフトで割り当て直したキーは、サインインした後でないと効きません。

`F12`はWindowsがデバッガ用に予約しているため、ホットキーには使わないでください(1.0.0の既定は`Ctrl` + `Alt` + `F9`〜`F12`でしたが、1.0.1で`F8`〜`F11`に変えました)。

## コマンドで使う

展開したフォルダの`DisplayRescueService.exe`を使うと、同じことをコマンドでもできます。「管理者」と書いたものは、管理者のPowerShellで実行してください。

| コマンド | 内容 |
|---|---|
| `.\DisplayRescueService.exe install` | インストール(管理者) |
| `.\DisplayRescueService.exe uninstall` | アンインストール(管理者) |
| `.\DisplayRescueService.exe bindings` | 今の割り当てを表示 |
| `.\DisplayRescueService.exe bind clone Ctrl+Alt+D` | 割り当てを変える(管理者) |
| `.\DisplayRescueService.exe unbind external` | 割り当てを外す(管理者) |
| `.\DisplayRescueService.exe extend` | 今すぐ切り替える |
| `.\DisplayRescueService.exe dump` | 今の画面構成を表示 |
| `.\DisplayRescueService.exe version` | 版を表示 |

`bind` / `unbind` / 切り替えで使う操作の名前は次のとおりです。

| 名前 | 画面構成 |
|---|---|
| `extend` | 拡張 |
| `clone` | 複製 |
| `internal` | メインのみ |
| `external` | サブのみ |

`bind`のキーは、`Ctrl` `Alt` `Shift`を`+`でつなぎ、最後にキーを1つ書きます。

- 使えるキーの名前: `F1`〜`F24`、`A`〜`Z`、`0`〜`9`、`Space`、`Enter`、`Left`、`Pause`、`Num0`など
- 名前の無いキーは、仮想キーコードで書けます(例: `0xBA`)
- `Ctrl`も`Alt`も付けないキーは、末尾に`--force`が要ります(理由は上の注意を参照)

## ログ

ログは`C:\ProgramData\DisplayRescue\rescue.log`(UTF-8)に残ります。1 MBを超えると`rescue.log.1`に移します。

```powershell
Get-Content C:\ProgramData\DisplayRescue\rescue.log -Wait
```

## 制限

- ロックした直後は、少しのあいだキーが効かないことがあります。
- UACの確認画面が出ている間は、キーが効きません。
- リモートデスクトップで接続しているときのキー入力は、リモート側に届きます。手元の物理モニタは切り替わりません。
- メッセージは日本語だけです。

## セキュリティ

- サービスはSYSTEM(LocalSystem)の権限で動きます。
- 受け取るのは、割り当てたキーの組み合わせだけです。ほかのキー入力は記録しません。
- キーの設定(`HKLM\SOFTWARE\DisplayRescue`)とログのフォルダに書き込めるのは、管理者とSYSTEMだけです。ログは一般ユーザーも読めます。
- サインイン中のユーザーは誰でも`sc.exe control DisplayRescue 130`を送れます。これでできるのは、割り当ての読み直しだけです。

## 仕組み

1. キー入力は、そのとき操作中のデスクトップ(入力デスクトップ)にしか届きません。サインイン中は通常のデスクトップ(`Default`)、ロック画面とログイン画面は`Winlogon`デスクトップです。サービス(セッション0)には、どちらの入力も届きません。
2. そこでサービスは、入力デスクトップに待ち受け役(`DisplayRescueService.exe watch`)を起動します。通常のデスクトップではサインイン中のユーザーの権限で、ロック画面とログイン画面ではSYSTEMの権限で動きます。ロック、ロック解除、サインインのたびに置き直します。
3. 待ち受け役は、割り当てたキーだけを`RegisterHotKey`で登録します。キーが押されたら、`SetDisplayConfig`にトポロジ(`SDC_TOPOLOGY_*`)を指定して切り替えます。

## ソースからビルドする

必要なもの:

- Visual Studio 2026(ツールセットv145)と「C++によるデスクトップ開発」ワークロード
- [WIL](https://github.com/microsoft/wil)(NuGetで自動的に復元されます)

C++20、x64でビルドします。ランタイムは静的リンク(`/MT`)です。

```powershell
msbuild DisplayRescue.slnx /t:restore /p:RestorePackagesConfig=true
msbuild DisplayRescue.slnx /p:Configuration=Release /p:Platform=x64
```
